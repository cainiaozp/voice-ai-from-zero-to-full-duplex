# 课程纠错及容易误读的地方

这份清单明确保留学习过程中发生的认知修正，而不是为了“看起来正确”而删去疑问。

1. **ESC-50 狗叫图像大片亮黄**：早期根据视觉解释为狗叫谐波为主；用户的像素分布统计与归一化代码指出，关键主因是短片段各自峰值归一化放大静音背景。参见 [`qa/05-esc50-case-study.md`](qa/05-esc50-case-study.md)。
2. **Whisper Encoder 直接输出汉字？** 不对。它输出时间特征；Decoder 再结合文字历史与 Cross Attention 预测 Token。
3. **“VQ-VAE 会生成猫照片”**：单纯重建模型不等于条件文字生成器；另需 Transformer/Diffusion 等学习生成 Token 或 Latent 的分布。
4. **“Codec 就是 TTS”**：Codec 训练的是已有声音的压缩和恢复，TTS 学文字到声音表示。
5. **“相差180°的纯音是另一个音高”**：不对。单独稳态纯音的音高不变，但与原纯音叠加可相消。
6. **“Flow 的 t 是音频秒数”**：不对。Flow t 是生成积分进度，Mel 的横轴才是音频时间。
7. **“Qwen3-TTS 没有 Flow”**：不能泛化；12Hz多码本 Codec 路线与其他版本的声学生成路径不同。
8. **“VAD=用户说完”**：不对。语音活动停止不能完全判断语义话轮结束。
9. **“因果注意力让模型必须等整句”**：不对。注意力因果性与请求调度/帧率是两个不同问题。
10. **“KV Cache 就存在于 safetensors 文件”**：不对。权重一般由磁盘文件加载，KV 是会话运行时缓存，多数情况下常驻 GPU 显存。
11. **“Moshi 的低帧率意味着任何服务器都是200ms端到端”**：不对。帧长、模型运算、缓冲和真实用户交互等待不是同一个指标。
12. **“静音不会占上下文”**：如果静音帧仍送入主模型，它们照样增加时间位置；可采取待机或固定窗口管理。
13. **“Sparse 就是 MoE”**：MoE 是按专家稀疏激活，Sparse Attention、剪枝等属于其他形式。
14. **“MoE 激活参数少=显存必然小”**：专家权重总数仍可能很大；通常需要保存全部专家或显式卸载。
15. **“所有之前的 WAV/图片都能公开上传”**：不可假设。公开仓库应优先合成数据、清理私人录音及外部授权内容。
