# 实验复盘：ESC-50 中 dog / rooster 的 Log-Mel 大片亮黄色

本节整理用户亲自统计并指出的失真原因。这里的数值来自当时的实验交流，**不是我们重新从 ESC-50 原始文件计算得到的**。原数据集没有包含在本仓库。

## 观察到的统计

| 类别 | 频谱像素 >=0.9 比例 | 频谱 p50 |
|---|---:|---:|
| dog | **80.1%** | **约1.00** |
| rooster | **40.6%** | **0.53** |
| rain | **1.1%** | **0.75** |
| crickets | **1.0%** | **0.53** |

在此前的目视讲解中，曾把 dog 的亮黄重点解释为“狗叫的谐波峰”。**后续定量统计与代码检查推翻了这个主因判断**。

## 真正原因：逐片段独立峰值归一化

完整5秒被切成5个1秒片段，每片段分别运行类似：

```python
db = 10*torch.log10(mel.clamp_min(1e-8))
db = db - db.amax()             # 关键：每一秒都有独立最大值
norm = (db.clamp(-80,0)+80)/80
```

一个全是安静背景的片段，其峰值可能仅仅是噪声或数值下限。当背景 dB 分布窄时，大部分 bin 距离自身最大值只有几 dB，于是归一化后靠近1；它们拼到完整频谱中就变成一大片统一亮黄。真正有狗叫的片段反而使背景比峰值低很多 dB，归一化后更暗。

这不是“安静声音比狗叫更响”，而是**绝对响度被片段局部参考值抹掉**。

## 三种对照策略

A. **每秒独立参考**：局部响度不变性强，但会破坏跨片段能量关系。  
B. **整段5秒统一参考**：保留同一段录音内部的相对能量变化。  
C. **全局固定 dB 参考**：保留绝对参考强度；需先校准量纲、录音增益与动态范围。

此外，完全数字静音 `mel` 被 clamp 到同一个极小值时，再减去自身最大值会导致所有 bin 直接变成0dB，相应归一化值为1。

## 标签粒度的第二个问题

如果 5 秒仅约 1 秒包含狗叫，随机抽一个 1 秒片段并继承 `dog` 标签，那么大概率抽到纯背景却仍标为 dog，模型可以依赖场景背景捷径，泛化受损。

建议实验：保留官方 ESC-50 折分，比较 A/B/C、完整5秒训练和 MIL 聚合；报告 Macro-F1、`dog/rooster/glass_breaking` 类别召回、混淆矩阵和错误样本，而不能仅凭单图颜色下结论。

`extras/esc50-normalization/compare_normalization.py` 不需要下载 ESC-50：默认生成一段“4秒安静背景 + 1秒事件”的合成音频，用同样的数学处理直接展示黄屏伪特征。可替换为你自己有权使用的音频文件。该脚本的数值结果**不等于**这里的原始 dog 数据统计。

```bash
python extras/esc50-normalization/compare_normalization.py --out outputs/esc50_compare.png
```
