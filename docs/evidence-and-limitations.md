# 证据、运行状态与局限

本仓库的目标是帮助学习、检查与复现实验，而不是暗示我们已经用真实模型证明所有教学结论。

## 状态标记

| 类型 | 含义 | 例子 |
|---|---|---|
| 教学 toy，实际曾执行 | 只演示原理，数据/标签通常为合成 | AudioCNN 三分类、Flow toy、MTP toy、Moshi 双流 toy、会话模拟器 |
| 传统信号处理，实际曾执行 | PCM、STFT、Mel、相位恢复，没有神经模型 | 第01课、第05课 Griffin–Lim |
| 官方预训练接口示例 | 提供源码入口，但权重下载、兼容性和实际结果由本地验证 | Whisper、EnCodec、Silero、CosyVoice2、Qwen3-TTS |
| 外部公开研究 | 官方论文、README、工程文章支持的结构性说明 | Mimi 12.5Hz、CosyVoice2、OpenAI 实时系统公开讨论 |
| 工程建议/教学假设 | 可行设计，不代表某个闭源产品采用同样实现 | `generation_id`、自定义 Gateway、仿真280ms等 |

## 代码恢复与素材处理

这些文件是从本次学习对话中可访问的会话附件恢复的教学实验源码。`ORIGINAL-LAB-NOTES.md` 尽可能保留此前实验说明。为避免公开发布隐私或第三方授权不明的素材，本仓库没有原始私人人声录音或 ESC-50 数据集，只包含数学合成的 WAV 与对应图形。第四/五课公开可运行的示例音频使用新生成的数学音调，因此重新运行后的 SNR/波形不会与之前针对语音素材的结果逐样本相同。

## 关于聊天记录

`docs/qa/` 是依据当前对话**可见内容**重构的问答记录，不是聊天平台导出的逐字记录。没有强行补出不存在的源对话片段，也没有导出内部推理日志。若需要保留聊天原文，请另从官方数据导出渠道取得，注意删除私人数据后再公开。

## 不能混为一谈的指标

- 80ms Codec 帧时长 ≠ 模型推理80ms ≠ 端到端回答延迟80ms。
- `Softmax=54.6%` ≠ 测试准确率54.6%。
- 训练 toy Loss 下降 ≠ 真实 S2S 语音质量提升。
- 激活参数少 ≠ MoE 全模型权重占用小。
- 单个示例中的“某次模拟打断成功” ≠ 系统在真实网络下 P95/99 打断延迟。
- Ring KV 固定窗口 ≠ 具备永久长期记忆。
